1. Local AI Code Review (`review_code.py`)

ตรวจทานวิเคราะห์ไฟล์โค้ดในเครื่องแบบ Local เพื่อหา **Bugs**, **Security Vulnerabilities** (XSS, Sensitive Data Leaks) และ **Performance Bottlenecks** ด้วยโมเดล qwen2.5-coder:0.5b ผ่าน Ollama Service

python3 review_code.py market_monitor.py
จุดเด่นและระบบความปลอดภัย:
  • Auto-Start Ollama Service: หากบริการ Ollama บนพอร์ต 11434 ยังไม่ได้เปิด ระบบจะสั่งเปิด ollama serve ในพื้นหลังให้อัตโนมัติ
  • CPU Optimized: จำกัดความยาวโค้ด input 5,000 ตัวอักษร และตั้งค่า num_predict: 300 เพื่อประมวลผลได้อย่างรวดเร็ว ไม่หมดเวลา (Timeout)
  • Privacy 100%: ทำงานบน Local Machine ทั้งหมด ข้อมูลโค้ดไม่ถูกส่งออกนอกเครื่อง
จำลองสถานการณ์การใช้งาน review_code.py

2. Telegram Control Bot & Live Sessions (`bot.py`)
python bot.py เริ่มต้นบอต Telegram

เปิดใช้งานบอต Telegram สำหรับสั่งงาน AI CLI (AGY), ดึงข่าว Forex, สั่งตรวจวิเคราะห์ราคาทอง และควบคุมเครื่องแบบ Live Session

python bot.py
คำสั่งและการควบคุมในแชต Telegram
💬 คำสั่งหลักใน Telegram Chat
  • /live [ข้อความ] — เปิด Interactive Session แยกเฉพาะแชต เพื่อคุยโต้ตอบกับ AI ต่อเนื่อง
  • /end — ปิดและจบ Live Session ปัจจุบัน
  • /new — ล้างประวัติเพื่อเริ่ม Interactive Session ใหม่
  • /cancel — ยกเลิกงานหรือสคริปต์ที่กำลังประมวลผลอยู่
  • /help — แสดงรายการคำสั่งทั้งหมดที่มีให้ใช้งานใน Telegram
🔐 การตั้งค่าความปลอดภัย (Private Chat ID)
กำหนด ALLOWED_CHAT_IDS=6649449367 ในไฟล์ .env เพื่ออนุญาตเฉพาะ User ID ของคุณในการสั่งงานบอต
3. เครื่องมือวิเคราะห์ตลาด Forex & Gold (`market_monitor.py`)
python market_monitor.py วิเคราะห์ความสัมพันธ์ราคาทอง

คำนวณและวิเคราะห์ Correlation ระหว่างราคาทองคำ (Gold Futures), พันธบัตรรัฐบาลสหรัฐ (US10Y Yield Proxy), ดอลลาร์อินเด็กซ์ (DXY) และน้ำมันดิบ (WTI)

python get_forex_news.py --format html --limit 5 --no-cache

นับคลื่น Elliott Wave โดยอัตโนมัติจากราคา Pivot จุดกลับตัวที่ยืนยันแล้ว รองรับหุ้น สินทรัพย์ Crypto (BTCUSDT) และ ทองคำ

python elliott_analyzer.py --symbol BTCUSDT --interval 4h --format json

6. Antigravity AGY CLI & TUI Slash Commands (`/`)
agy --flags & Subcommands ตัวเลือกและพารามิเตอร์ CLI

พารามิเตอร์หลักสำหรับสั่งงาน Antigravity CLI จาก Terminal

ดูรายการ CLI Flags ที่สำคัญ
  • -p | --prompt <text> — สั่งงานสั้นๆ แบบรันครั้งเดียวจบ แล้วพิมพ์ผลลัพธ์ออกจอ
  • --dangerously-skip-permissions — อนุมัติสิทธิ์การเขียนไฟล์และรันคำสั่งทั้งหมดอัตโนมัติ
  • --effort <low | medium | high> — ปรับระดับความลึกในการคิดวิเคราะห์ของ AI
  • --mode <accept-edits | plan> — ตั้งโหมดเริ่มต้นว่าจะเขียนไฟล์ทันที หรือเน้นวางแผนก่อน
  • --sandbox — เปิดโหมดจำกัดสิทธิ์ความปลอดภัย Sandbox
TUI Slash Commands (ในหน้าแชต /) คำสั่งย่อยใน TUI Mode

คำสั่งลัด Slash Commands สำหรับสั่งงานในหน้าต่างโต้ตอบ TUI Chat

ดูรายการ Slash Commands ทั้งหมด
  • /goal [คำอธิบายเป้าหมาย] — สั่ง AI ลุยงานต่อเนื่องยาวข้ามคืน วนลูปแก้และรันเทสต์จนกว่าจะสำเร็จ 100%
  • /schedule [ระยะเวลา / เงื่อนไข] — ตั้งเวลานาฬิกาปลุกหรือ Cron Job ให้ AI กลับมาเช็กงานตามรอบเวลา
  • /plan [เป้าหมาย] — บังคับให้ AI สรุปแผนพิมพ์เขียว (Blueprint) ให้มนุษย์อนุมัติก่อนเริ่มแตะโค้ด
  • /grill-me — โหมดสัมภาษณ์ AI จะยิงคำถามถามคุณยิบๆ เพื่อเคลียร์ข้อสงสัยก่อนวางแผนงาน
  • /teamwork-preview — แตกงานขนานให้ทีม Subagents สปอว์นช่วยกันรันงานพร้อมกัน
  • /learn — บันทึกสไตล์การเขียนโค้ดและคำสั่งสอนของคุณลงโฟลเดอร์ .gemini/rules/
  • /compact — ย่อสรุปประวัติบทสนทนาเพื่อประหยัด Context Window
  • /copy — คัดลอกผลลัพธ์ล่าสุดของ AI เข้า Clipboard ของเครื่องทันที
